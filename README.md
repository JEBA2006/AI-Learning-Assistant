# 🎓 AI Learning & Study Assistant

An AI-based learning assistant that helps students create study plans, ask questions from course materials, and generate quizzes.

## 🚀 Features

* 📅 Create personalized learning plans
* 🔎 Ask questions from course materials
* 📝 Generate quizzes from study material
* 🤖 Uses multiple specialized agents
* 🌐 Simple web interface using Streamlit

## 🧩 Agents

### 1. Learning Plan Agent

Creates a day-by-day study plan based on the topic and number of days.

### 2. Question Answering Agent

Answers questions using the provided course material.

### 3. Quiz Generation Agent

Generates quiz questions from the provided study material.

## ▶️ How to Run

Activate the virtual environment:

```bash
venv\Scripts\activate
```

Run the Streamlit application:

```bash
streamlit run app.py
```

The application will open in the browser.

## 🎯 Project Objective

The objective of this project is to develop an intelligent learning assistant that supports students in planning their studies, understanding course materials, and practicing through automatically generated quizzes.
